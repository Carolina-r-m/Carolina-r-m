<h2>📌 Proyectos destacados</h2>

<h3>🏰 CaceresGo — TFG</h3>

Plataforma web de gamificación turística basada en geocaching y geolocalización, pensada para descubrir los monumentos y lugares de interés de Cáceres mediante rutas y retos interactivos.

**Funcionalidades principales:**

- 🗺️ Exploración de rutas y puntos de interés.
- 📍 Geolocalización para ayudar a los usuarios a descubrir lugares.
- 📱 Validación de visitas mediante códigos QR o códigos.
- 🏆 Sistema de puntos y clasificación de usuarios.
