<h2>📌 Proyectos destacados</h2>

<h3>🏰 CaceresGo — TFG</h3>

Plataforma web de gamificación turística basada en geocaching y geolocalización, pensada para descubrir Cáceres de una forma interactiva.

**Funcionalidades principales:**

- 🗺️ Exploración de rutas y puntos de interés.
- 📍 Geolocalización para descubrir lugares turísticos.
- 📱 Validación de visitas mediante códigos QR o códigos.
- 🏆 Sistema de puntos y clasificación de usuarios.
